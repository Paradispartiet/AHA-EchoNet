Canonical Sync · Production pilot

Denne siden er kun for den første eksplisitte én-profil-piloten etter at production-aktivering er gjennomført. Den er ikke koblet til Home, login eller bakgrunnskjøring.

Fail-closed og én profil.

Ingen auth-lesing, nettverkskall eller sync skjer ved page load. URL-porten må åpnes eksplisitt med ?ahaCanonicalProductionPilot=1. Selve kjøringen krever production-API-origin, samtykke og eksakt bekreftelsesfrase.

Workspace kan ikke skrives inn. Ved eksplisitt kjøring utledes det som personal-<innlogget JWT-subjekt>, samme identitet som production-databasen bootstrapper. NestJS-serveren avviser samtidig alle andre profiler med sin beskyttede pilot-allowlist.

Viktig: I motsetning til staging bruker denne piloten det ekte lokale canonical-lageret. Bootstrap og pull kan derfor oppdatere lokale AHA-data. Rå payload, JWT-subjekt, workspace-ID og serverState vises ikke i resultatflaten.
