AHA · beskyttet operatorflate

Canonical Sync · Production pilot

Denne siden er en diagnostisk operatorflate for den aktive bounded production-piloten. Vanlig pilotbruk skjer fra AHA Home via «Synkroniser nå». Ingen sync er koblet til login eller bakgrunnskjøring.

Fail-closed og protected allowlist.

Ingen auth-lesing, nettverkskall eller sync skjer ved page load. URL-porten må åpnes eksplisitt med ?ahaCanonicalProductionPilot=1. Selve kjøringen krever production-API-origin, samtykke og eksakt bekreftelsesfrase.

Workspace kan ikke skrives inn. Ved eksplisitt kjøring utledes det som personal-<innlogget JWT-subjekt>, samme identitet som production-databasen bruker. NestJS-serveren tillater bare profiler som finnes i den beskyttede bounded pilot-allowlisten.

Viktig: I motsetning til staging bruker denne piloten det ekte lokale canonical-lageret. Bootstrap og pull kan derfor oppdatere lokale AHA-data. Rå payload, JWT-subjekt, workspace-ID og serverState vises ikke i resultatflaten.

Production har nå to verifiserte pilotprofiler. Denne siden velger aldri profil eller workspace manuelt; innlogget Supabase-identitet bestemmer alltid privat workspace, og cross-profile tilgang skal fortsatt avvises.
